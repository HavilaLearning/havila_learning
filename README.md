# Havila Learning — Website v2

Static website prepared for zero-hosting-cost deployment.

## Recommended deployment
GitHub Pages with the existing domain `havila.company`. GitHub Pages is available with GitHub Free for public repositories and supports custom domains and HTTPS.

## Important
- `CNAME` is set to `havila.company`.
- Keep existing email DNS records intact. Do not replace MX records used by email.
- The site links to the Payhip product page for checkout.
- Contact page uses email as a fallback; connect a form provider later if desired.
