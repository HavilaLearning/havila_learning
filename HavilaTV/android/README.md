# Havila TV — Android TV

## Etapa 3

Projeto Android TV / Google TV inicial da Havila TV.

### Objetivo

Criar o aplicativo nativo com navegação por comando remoto, catálogo de categorias/canais e player de vídeo.

### Stack prevista

- Kotlin
- Android TV / Google TV
- Jetpack Compose for TV
- AndroidX Media3 para reprodução de vídeo

### Próxima implementação

1. Criar projeto Gradle Android compilável.
2. Implementar Home.
3. Implementar navegação por D-pad.
4. Implementar ecrã de canal.
5. Integrar Media3/ExoPlayer com streams HLS autorizados.

Os streams comerciais serão adicionados somente depois de confirmados os direitos de distribuição.
